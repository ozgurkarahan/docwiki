# S600 Stopped - icing

> FICTIONAL SAMPLE - Contoso Renewables, Quellmoor Ridge Wind Farm and every organisation, person, product and value in this wiki are invented. Not for operational use.

S600 Stopped - icing is a status code used for [WTG-12](../asset/wtg-12.md), [WTG-09](../asset/wtg-09.md), [WTG-03](../asset/wtg-03.md), and [WTG-02](../asset/wtg-02.md) in SCADA alarm and status logs.[^c1][^c2][^c3][^c4][^c5][^c6][^c7][^c8] In the cited log, icing alarms [A7001](../alarm-code/a7001.md) led to S600 status starts for those turbines, with later clears and S600 ends recorded.[^c1][^c2][^c3][^c4][^c5][^c6][^c7][^c8]

## Facts

- On 2026-04-01, icing alarms [A7001](../alarm-code/a7001.md) led to S600 Stopped - icing status starts for [WTG-12](../asset/wtg-12.md), [WTG-09](../asset/wtg-09.md), [WTG-03](../asset/wtg-03.md), and [WTG-02](../asset/wtg-02.md), with later clears and S600 ends recorded for each turbine in this part.[^c1][^c2][^c3][^c4][^c5][^c6][^c7][^c8]

## Timeline
