# S430 Curtailed - grid operator setpoint

> FICTIONAL SAMPLE - Contoso Renewables, Quellmoor Ridge Wind Farm and every organisation, person, product and value in this wiki are invented. Not for operational use.

S430 Curtailed - grid operator setpoint is a status code used in SCADA alarm and status logs.[^c1][^c2][^c3][^c4][^c5][^c6][^c7][^c8] In the current log, [WTG-01](../asset/wtg-01.md) through [WTG-12](../asset/wtg-12.md) entered S430 Curtailed - grid operator setpoint at 20.0 MW on 2026-07-14.[^c1][^c2][^c3][^c4] On 2026-07-15 and 2026-07-16, the same status started at about 08:00 and ended at about 18:00 for WTG-01 through WTG-12.[^c5][^c6][^c7][^c8]

## Facts

- On 2026-07-14, [WTG-01](../asset/wtg-01.md) through [WTG-12](../asset/wtg-12.md) started S430 Curtailed - grid operator setpoint at 20.0 MW; END entries are shown through WTG-12 across the part boundary.[^c1][^c2][^c3][^c4]
- On 2026-07-15 and 2026-07-16, S430 Curtailed - grid operator setpoint at 20.0 MW started for WTG-01 through WTG-12 at about 08:00 and ended at about 18:00.[^c5][^c6][^c7][^c8]
