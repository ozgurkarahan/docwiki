# A4105 Pitch system fault

> FICTIONAL SAMPLE - Contoso Renewables, Quellmoor Ridge Wind Farm and every organisation, person, product and value in this wiki are invented. Not for operational use.

A4105 Pitch system fault is an alarm code in the reviewed registry.[^c1][^c2][^c3][^c4][^c5][^c6][^c7][^c8][^c9][^c10][^c11][^c12][^c13][^c14][^c15][^c16] In SCADA alarm and status logs, it was recorded on [WTG-12](../asset/wtg-12.md), [WTG-05](../asset/wtg-05.md), [WTG-06](../asset/wtg-06.md), and [WTG-10](../asset/wtg-10.md) with [S510 Stopped - fault](../status-code/s510.md) events.[^c1][^c2][^c3][^c4][^c5][^c6][^c7][^c8][^c9][^c10][^c11][^c12][^c13][^c14][^c15][^c16] The logged values were 1 axis, 2 axis, and 3 axis.[^c1][^c2][^c3][^c4][^c5][^c6][^c7][^c8][^c9][^c10][^c11][^c12][^c13][^c14][^c15][^c16]

## Facts

- On 2026-04-14 and 2026-04-16, [WTG-12](../asset/wtg-12.md) logged A4105 Pitch system fault events with [S510 Stopped - fault](../status-code/s510.md) starts and ends; the first event had value 1 axis and the second had value 2 axis.[^c1][^c2][^c3][^c4]
- [WTG-05](../asset/wtg-05.md) raised A4105 Pitch system fault with value 1 axis on 2026-08-03, started S510 Stopped - fault, then cleared A4105 and ended S510 about two hours later.[^c5][^c6][^c7][^c8]
- [WTG-06](../asset/wtg-06.md) raised A4105 Pitch system fault with value 3 axis on 2026-08-05, started S510 Stopped - fault, then cleared A4105 and ended S510 shortly after midnight on 2026-08-06.[^c9][^c10][^c11][^c12]
- [WTG-10](../asset/wtg-10.md) raised A4105 Pitch system fault with value 2 axis on 2026-08-23 01:43:03, entered S510 Stopped - fault, cleared A4105 at 04:03:03, and ended S510 at 04:03:33.[^c13][^c14][^c15][^c16]
