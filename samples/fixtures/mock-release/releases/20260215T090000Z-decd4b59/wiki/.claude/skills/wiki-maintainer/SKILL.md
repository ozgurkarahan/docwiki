# Wiki maintainer

1. Add documents to the raw input folder; never edit generated pages by hand.
2. Read `_meta/quality.md` after every run and fix failing gates at their source.
3. Review open proposals before accepting new entities, glossary terms or topics.
4. Check `log.md` to confirm that each change was recorded.
