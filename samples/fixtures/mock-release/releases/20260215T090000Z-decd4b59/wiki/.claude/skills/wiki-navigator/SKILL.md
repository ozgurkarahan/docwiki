# Wiki navigator

1. Read `index.md`, then `topics/index.md`, `entities/index.md` and `sources/index.md`.
2. Expand acronyms and translate terms with `glossary.md`.
3. Check `log.md` for recent changes before answering questions about recency.
4. With the DocWiki MCP server, use `search`, `read_page`, `get_index` and `get_links`.
5. Without the server, read the Markdown files directly; links are relative paths.
