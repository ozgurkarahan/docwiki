## Regenerating the images

The images in [`assets/`](assets) are generated by scripts, with the site's palette and no
third-party logos:

```bash
uv run python scripts/docs/architecture_svg.py           # assets/architecture.svg
uv run python scripts/docs/architecture_svg.py --check   # fails when the SVG is stale
uv run --extra gen python scripts/docs/social_preview.py # assets/social-preview.png (1280x640)
```

Use `social-preview.png` as the repository's social preview image (repository settings, General,
Social preview). Images and diagrams under `docs/` are licensed CC BY 4.0 like the sample content.
