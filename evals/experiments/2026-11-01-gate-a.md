# Gate A - does meaning help? (offline pilot)

Decision record of the words and meaning search plan (spec CHANGELOG v1.10). This file states the
criteria **before** the run that judges them; the results are appended below the line, pass or
fail.

## Question

Does fusing a semantic lane (embeddings) with today's lexical ranking bring back the questions the
lexical search misses (paraphrases, English questions about French documents) without losing any
it already finds and without breaking a filter?

## Setup (frozen before the blind run)

- Release: the release currently served, copied read-only; the same copy for both modes.
- Measure: `evals/retrieval_bench.py --mode lexical|hybrid`, candidate ranking of
  `answer_context` (one row per section or source locator, audience-filtered), depth 50.
- Semantic lane: every `search.db` row embedded with `text-embedding-3-small`, 512 dimensions,
  rule `embed-input-v1` (title, section heading, body). The question is embedded verbatim (one
  call per question). Cosine similarity over the rows that pass the **same filters** as the
  lexical search (`within`, language tree), then the same deduplication, audience check and
  skipped page types as `answer_context`; brute-force numpy search.
- Fusion: reciprocal rank fusion, `k = 60`, the first **50 candidates per lane**, ties broken by
  best rank in either lane, lexical first, then key.
- Tuning: these values may change on the tune set (`evals/golden/retrieval-tune.jsonl`) only;
  the values used for the blind run are committed in this file before it.
- Paired: lexical and hybrid run on the same release, the same day, the same question file.

## Criteria (blind decision set, `retrieval-blind.jsonl`, one pass, aggregates only)

A question is **found** when every one of its required citations ranks in the first 10
candidates (`hit_all@10`; `hit_any@10` is reported too).

**Continue** to S4 only if all three hold:

1. Hybrid finds **at least 3 more** questions than lexical among the `paraphrase-fr` and
   `en-to-fr` probes together (net: `gained - lost` of `paired_vs_lexical_hit_all@10`, summed over
   the two probe kinds).
2. **0 loss** on the `lexical-control` probes: no control question found by lexical is missing in
   hybrid (`lost == 0` in `paired_vs_lexical_hit_all@10`: each question is also ranked by the lexical
   lane alone in the same run, and only the counts are written).
3. **0 violation** of scope, language tree or audience in the hybrid candidates.

Otherwise: stop F1/F2, publish this result, remove the `embed` deployment, go to S7 without hybrid,
then S8 and S9. `multi-chantier` probes are reported, not judged (their fix is F3).

## Cost

Measured from the run's usage ledger (rows + questions), indicative price 0.02 USD per million
tokens; expected well under 0.10 USD.

## Frozen settings (after the tune set, before the blind run)

Tune run of 2026-11-01 (`evals/results/2026-11-01-retrieval-hybrid-tune.json`, 12 probes, paired
with the committed lexical file of the same date): hybrid finds 1 more `paraphrase-fr` question,
loses none, 0 violations, and raises the MRR of every probe kind (paraphrase 0.19 -> 0.67,
en-to-fr 0.83 -> 1.00, lexical-control 0.78 -> 1.00, multi-chantier 0.44 -> 0.78). 3 852 rows,
556 675 row tokens, 0.011 USD. No reason to move the values: **`k = 60`, 50 candidates per lane,
depth 50, 512 dimensions** are the values of the blind run.
